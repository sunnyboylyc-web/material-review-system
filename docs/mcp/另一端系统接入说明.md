# 素材视界只读MCP：连接与调用说明

## 最小配置（服务1.2.3 / guide 1.1.2）

使用者只填写三项：

| 配置项 | 填写方式 |
|---|---|
| 服务器名称 | 素材视界，可自定义 |
| 传输类型 | HTTP，对应Streamable HTTP；不是STDIO或旧双端点SSE |
| 服务器URL | 复制维护方单独TXT中的完整URL，包含`?API_KEY=...` |

不设置单独密钥字段，不填写Authorization或其他自定义Headers。客户端通过initialize和tools/list自动发现现有7个工具，用户不需要配置业务接口或工具参数表。建议调用超时300秒，标准SDK自动管理Content-Type、Accept和协议头。

仓库示例只含`https://mcp.example.invalid/mcp?API_KEY=<OPERATOR_DELIVERED_SECRET>`占位符；真实完整URL仅在受限TXT中单独交付，不放说明包、Git或公开配置。配置JSON字段名为建议映射，并非所有连接器的统一格式。若界面强制选择认证类型，选“无／不额外添加认证头”；这只表示客户端不增加Header，服务端仍验证URL密钥。

整个URL等同密码：后端加密或受限存储；编辑/列表掩码显示查询值；日志、异常、监控、导出与模型上下文均不得包含完整URL。不要在普通浏览器地址栏打开或分享它，避免浏览历史/同步保存。客户端不得丢弃或重复拼接查询参数，不修改域名、关闭TLS校验或随意跟随跨域重定向。

## 认证与兼容

服务使用原有外部密钥验证API_KEY，密钥未更换。旧Authorization: Bearer方式继续兼容，不要求使用者填写。URL密钥或旧Header任一方式有效即可；若同时出现，两者必须各自正确且一致。空值、重复API_KEY、重复Authorization、错误或冲突认证统一HTTP401，保留旧错误名MCP_BEARER_TOKEN_REQUIRED_OR_INVALID。密钥不是工具参数，禁止放进arguments。

服务入口在鉴权后移除URL密钥和Authorization再交给MCP SDK；正式部署关闭本系统两个精确MCP入口的原始访问/错误日志及Uvicorn访问日志，防止查询密钥落日志。其他站点日志不变。新增上游代理、CDN或APM时也必须自行脱敏；服务无法清除客户端或第三方已经记录的URL。

网站登录与MCP认证独立，网站当前仍免登录。MCP读取看板使用服务器专用内部只读身份，六类GET白名单，不依赖网站会话。内部凭据不同于对外密钥，只在服务器，不向客户端交付。以后增加登录/SSO仍须保留MCP独立入口和内部服务链。

共享外部密钥可读取全部启用项目，没有每用户/每项目权限。内部读取认证失败UPSTREAM_SERVICE_AUTHENTICATION_FAILED由维护方处理，不向用户索要网站密码或内部密钥。更新MCP会使内存reportId失效，重新查询即可。

## 调用、日期、口径与限制

| 工具 | 必填arguments | 可选/默认 |
|---|---|---|
| get_data_guide | {} | 无；也可读dashboard://guide |
| list_projects | {} | 无；从projects[].id取ID，不猜名称/账户号 |
| get_period_review | query.project_id及四个统计日期 | query内两对测试日期；top_limit=10，1—200 |
| query_materials | query.report_id | group=overall，search=""，filters=[]，offset=0，page_size=20，include_daily_spend=false |
| get_material_trend | report_id、material_id | group=overall，与取得素材的明细组一致 |
| get_daily_top | project_id、date | limit=10，1—200 |
| get_project_freshness | project_id | 无；不是调度健康检查 |

四个必填统计日期为current_start本期开始、current_end本期结束、previous_start上期开始、previous_end上期结束。必须YYYY-MM-DD真实自然日，年份1900—2200，北京时间；首尾均含，开始≤结束，可同一天，含首尾最长3660天。本期与上期不强制等长/先后/不重叠；测试周期可跨出统计范围；服务未额外禁止未来日，缺数据须看coverage，不转0。

每对测试日期应均提供非空值，或两项省略/均null；一项非空会被拒绝。省略分别默认对应统计周期。Schema可检查required/类型/日期形状/单字段边界，客户端须启用format=date验证真实日期；成对、日期先后、年份范围和区间日数仍由服务端校验，标准JSON Schema不能比较两个日期字段。

连接后initialize、tools/list、get_data_guide、list_projects，再按工具Schema组参。准确inputSchema/outputSchema见tools-schema.json（由tools/list生成），正确参数例子见synthetic-calls.json。demo-project、demo-material和示例report_id均虚构，生产替换为工具返回值；JSON-RPC id与reportId不同。每次新连接重新发现Schema，支持$defs/$ref/required/anyOf/enum。

错误例子见error-examples.json：用虚构输入实际捕获缺参数和非法日期的MCP响应，以及HTTP401。先看HTTP状态和MCP isError，再读structuredContent。当前参数/业务错误是isError=true与content文本，**没有统一structuredContent.error.code/field/retryable对象**；诊断文字不是稳定字段解析协议。401返回JSON的error=MCP_BEARER_TOKEN_REQUIRED_OR_INVALID，缺/错/重复认证同样拒绝。当前一个有效共享密钥可读全部启用项目/7工具，**没有每Agent/每项目的权限范围**；403为Origin等传输防护，不能假称项目权限不足。

当前服务1.2.3、guide 1.1.2，period report仍1.0.0，业务计算不改；只补元信息和把既有校验写进Schema，合法调用名称/嵌套/默认值兼容，非法值可能更早被拒绝。新增返回字段应被容忍；未来若改必填项、删除/重命名参数或口径，必须说明兼容影响。服务补丁版本与snapshotFingerprint数据版本不同。

新看板请求读取当前已入库事实，无需网页刷新，不触发采集；旧reportId继续固定快照，要看更新须新建报告。snapshotFingerprint不是更新时间，createdAt/expiresAt只指MCP报告；freshness只指自动来源统计日，不证明人工最新日或完整覆盖。未实现更新推送。指标口径入口为get_data_guide，包含单位/公式/状态/覆盖/分组和分页边界；不要平均日比率或相减比率。

其他明确未实现：STDIO、OAuth、持久报告、全部单日素材检索、每日ROI/订单等非来源序列、完整采集健康接口、任何写工具。名称AI总量已有汇总，独立明细只有business/department；aigc是原有AIGC集合组，不能当成名称含AI总体。
